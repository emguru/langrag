# Cloud Infrastructure Acronym Glossary

| Term | Meaning |
|------|---------|
| VPC | Virtual Private Cloud |
| IAM | Identity and Access Management |
| SG | Security Group |
| AZ | Availability Zone |
| IRSA | IAM Roles for Service Accounts (EKS) |
| TF | Terraform (internal shorthand) |

Do not confuse SG (security group) with service gateway.
