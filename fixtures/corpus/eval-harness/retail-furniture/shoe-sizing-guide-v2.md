# Athletic Footwear Sizing Guide (2024)

Version 2.1 — replaces deprecated v1 sizing card.

## How to measure

Use a Brannock device or trace foot length on paper while standing. Measure both feet; order the larger size. Width codes run narrow (B), standard (D), wide (2E).

## Half sizes

Running shoes often need a half size up for toe box clearance during long runs. Dress shoes should match Brannock length without extra thumb space.
