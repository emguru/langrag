Research run sequence

What happens when a user submits a research topic in the showcase UI.

sequenceDiagram
  actor User
  participant UI as Showcase UI
  participant LG as research-agents
  participant Q as Qdrant
  participant BR as Bedrock
  participant LS as LangSmith

  User->>UI: Research topic
  UI->>LG: SSE stream
  LG->>Q: RAG retrieval
  Q-->>LG: Chunks
  LG->>BR: Claude invoke
  BR-->>LG: Response
  Note over LG: Coordinator Researchers Critic Synthesizer
  LG-->>UI: Stream report
  UI-->>User: Final output
  LG-->>LS: Traces
